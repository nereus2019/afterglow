余味 · Windows 便携版 1.1

本版新增：书籍分册 / 繁简体与英文别名检索、MusicBrainz 专辑来源、
iTunes 多区域检索、按月统计（页面顶部“月度统计”按钮）。

从旧版升级：先导出 JSON 备份并停止旧版，将新版解压到新文件夹，
启动后导入备份。如果旧版仍在运行，默认端口相同会打开旧版页面。
若找不到旧版的停止入口，可以重启电脑后直接启动新版。

适用：Windows 10 / 11，64 位 Intel / AMD 电脑。
已自带 Python 运行环境，无需安装 Python 或 Codex。

1. 将 ZIP 压缩包完整解压到普通文件夹，例如桌面或文档。
   不要直接在压缩包中启动，也不要只复制启动文件。
2. 双击「启动余味.cmd」，等待浏览器自动打开。
3. 如果浏览器未自动打开，访问 http://127.0.0.1:8765 。
4. 使用完毕可双击「停止余味.cmd」，记录不会丢失。
   关闭网页不会停止后台服务，重启电脑后需重新启动工具。

手机使用：
手机与这台电脑连接同一 Wi-Fi，在页面点击「在手机上打开」，
输入显示的地址。手机不能使用 127.0.0.1 或 localhost 访问电脑。
需要保持电脑开机。如果防火墙询问，仅在可信的专用网络允许访问。

数据与备份：
首次启动会自动创建 data 文件夹。记录保存在其中的 SQLite 数据库。
本压缩包不包含任何个人收藏记录。
需要迁移旧记录：在原电脑导出 JSON，然后在新电脑导入。
联网搜索和封面加载需要网络，已保存记录可以离线查看和编辑。
两台电脑分别运行时数据独立，不会自动同步。

故障排查：
- 启动失败时查看文件夹中的 server-error.log。
- 确保已经完整解压，且文件夹允许当前用户写入。
- 如果电脑已运行另一份余味，启动会打开已有服务。要使用新文件夹的
  独立数据，请先从旧文件夹运行「停止余味.cmd」。
- 此便携包不适用于 macOS、Linux 或 32 位 Windows。

运行环境许可证位于 runtime/LICENSE.txt。
